# mst.matrix

Современный веб-клиент **Matrix** с Material-подобным интерфейсом, светлой и тёмной темами, гибкой акцентной палитрой и полноценной работой с комнатами и сообщениями прямо в браузере.

![mst.matrix — светлая тема](docs/preview-light.png)

## Возможности

- **Вход в Matrix** по homeserver URL, Matrix ID и паролю, с сохранением сессии и автоматическим восстановлением.
- **Список комнат** с аватарами, последним сообщением, временем и непрочитанными.
- **Живые сообщения**: текст, Markdown-разметка, ссылки, изображения, аудио, видео и файлы.
- **Отправка**: текст, вложения, ответы на сообщения, эмодзи.
- **Реакции** на сообщения с агрегированным количеством.
- **Редактирование и удаление** собственных сообщений.
- **Индикатор набора текста** и автоматические read-receipts.
- **Поиск** по комнатам и по сообщениям в выбранной комнате.
- **Создание комнат** (публичных и приватных) и **вход по адресу/ID**.
- **Информация о комнате** со списком участников и возможностью покинуть её.
- **Профиль**: отображаемое имя, Matrix ID, статистика, сведения об устройстве.
- **Настройки**: светлая/тёмная/системная тема, 5 акцентных цветов, звук и браузерные уведомления.
- **Адаптивный интерфейс**: отдельная мобильная раскладка с выдвижным сайдбаром.
- **Демо-режим** без сервера: откройте [`/#demo`](https://kirilldual0987.github.io/mstUItest303/#demo) и посмотрите интерфейс.
- **E2EE**: клиент инициализирует Rust-крипто `matrix-js-sdk`, если браузер и homeserver это поддерживают. Зашифрованные сообщения, которые удалось расшифровать, отображаются как обычные.

![mst.matrix — тёмная тема](docs/preview-dark.png)

## Технологии

- [matrix-js-sdk](https://github.com/matrix-org/matrix-js-sdk) — работа с Matrix Client-Server API.
- [Vite](https://vitejs.dev/) — сборка статического бандла.
- Чистый JavaScript и CSS без UI-фреймворка: интерфейс собран вручную, поэтому загружается быстро и не зависит от сторонних компонентных библиотек.
- Иконки — собственный inline SVG-набор.

## Локальный запуск

```bash
npm install
npm run dev
```

Vite откроет адрес вида `http://localhost:5173`.

Для проверки production-сборки:

```bash
npm run build
npm run preview
```

## Сборка и GitHub Pages

Production-сборка складывается в каталог `docs/`:

```bash
npm run build
```

В настройках репозитория GitHub Pages должен быть выбран источник:

- **Branch:** `main`
- **Folder:** `/docs`

## Безопасность и ограничения

- Это полностью клиентское приложение: сообщения идут напрямую между браузером и вашим homeserver, промежуточного сервера нет.
- Access token сохраняется в `localStorage` (или `sessionStorage`, если снять «Запомнить меня»). Используйте клиент только на доверенном устройстве.
- Для E2EE нужен браузер с поддержкой WebAssembly и IndexedDB; ключи хранятся локально. Интерфейса верификации устройств и кросс-подписи пока нет.
- Голосовые и видеозвонки, а также push-уведомления при закрытой вкладке не входят в текущую версию.
